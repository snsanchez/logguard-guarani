# LogGuard Guaraní

LogGuard Guaraní is a defensive log analysis tool developed for educational and research purposes.

The project focuses on Apache logs generated by SIU Guaraní deployments used in Argentinian universities.

Current goals:

- Detect suspicious requests.
- Classify potential attacks.
- Assist system administrators.
- Generate structured datasets.
- Apply machine learning models for event classification.
- Serve as a future platform for AI-assisted security analysis.

The project is defensive-only.

It does not perform offensive security actions.
