# Knowledge Base

This directory contains the offline knowledge used by the SOC agent.

Goals:

- deterministic responses
- explainable recommendations
- minimal hallucinations
- reproducible analyses

Contents:

- incident playbooks
- MITRE ATT&CK mappings
- OWASP references
- CVE cache
- severity definitions

Knowledge can be refreshed using:

```bash
logguard_guarani --update-knowledge
```
